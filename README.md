# replaying-asd
Hi, welcome to Replaying (temporary name) !

This game is an indie, international project about being an ASD student in your first year of university, coded and conceived by two French students in web and game developement. We're also working in close collaboration with teachers from two different universities (our, in France, and another on in New Zealand). 

# "Well what is this game about ?", you may ask.
Nice question. We're following Emilie Moreau, a 21-year-old student with ASD that is going to be assisting her very first university lecture. To do so, you'll access an interactive website (which you're currently navigating on) and a game made on Unity, and embed in the page with WebGL. For the rest... why don't you find out about it by visiting our website ? It will be a better explanation than any words we could throw at you here ! 

# Can you tell us more about how you shared the workload ? 

To tell us about our domain of expertise, Marina is more into game developement, while I'm more into web development. Does that means she made the game and I made the website ? Not really. We both work work on both projects, even if it requires some compromises.
