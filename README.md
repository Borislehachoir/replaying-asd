# Through the Looking Glass
Hi, welcome to Through the Looking Glass (originally called Replaying ASD.... hence the repository name)!

This game is an indie, international project about being an ASD student in your first year of university, coded and conceived by two French students in web and game developement. We're also working in close collaboration with teachers from two different universities (our, in France, and another on in New Zealand).
